# 서버 코드 규칙

**적용 시점**: 요청을 받아 처리하는 서버 코드를 만들거나 고칠 때.

## 금지 / 허용
- 입력값은 서버에서 검증한다. 클라이언트가 보낸 값을 그대로 신뢰하지 않는다.
- 외부 API 키·비밀 값은 환경 변수로만 읽는다. 하드코딩 금지.
- 외부 서비스 호출에는 타임아웃과 실패 처리를 둔다.
- 에러는 `.claude/rules/error-handling.md` 형식을 따른다.
- 새 엔드포인트를 만들면 `.claude/skills/requirements/flows-and-pages.md` 라우트 목록을 갱신한다.
