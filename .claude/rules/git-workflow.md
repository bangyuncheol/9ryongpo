# git 워크플로 규칙

**적용 시점**: 항상. 커밋·브랜치·푸시·PR 관련 작업.

## 브랜치
- 기본 브랜치는 `main`. 직접 작업하지 않고 기능 브랜치를 만든다.
- 브랜치명: `feat/<주제>`, `fix/<주제>`, `docs/<주제>`.
- `main`에 강제 푸시하지 않는다.

## 커밋
- 커밋·푸시는 오너가 요청할 때만 한다.
- 커밋 메시지는 한글. 접두어는 `feat:` `fix:` `docs:` `refactor:` `test:` `chore:`.
- 문서만 바뀌면 `docs:`.
- `.env` 등 비밀 파일은 절대 커밋하지 않는다.
