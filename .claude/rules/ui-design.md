# UI 디자인 규칙

**적용 시점**: 화면·컴포넌트·스타일을 만들거나 고칠 때.

## 금지 / 허용
- 기존 컴포넌트가 있으면 재사용한다. 비슷한 컴포넌트를 새로 만들지 않는다.
- 색상·간격·글꼴은 디자인 토큰(테마 설정)으로만 쓴다. 임의 값 하드코딩 금지.
- 모든 인터랙티브 요소는 키보드로 조작 가능해야 하고, 이미지에는 대체 텍스트를 둔다.
- 사용자 문구는 한국어. 오류 문구는 `.claude/rules/error-handling.md` 를 따른다.
