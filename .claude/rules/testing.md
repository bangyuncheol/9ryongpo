# 테스트 규칙

**적용 시점**: 테스트를 추가·수정하거나 테스트 러너 설정을 바꿀 때.

## 금지 / 허용
- 버그를 고치면 가능한 한 재현 테스트를 함께 추가한다.
- 테스트는 실제 외부 서비스(결제·외부 AI API 등)를 호출하지 않는다. 모킹한다.
- 테스트가 실패한 상태로 완료라고 보고하지 않는다. 실패 출력을 그대로 전달한다.
- 테스트를 통과시키기 위해 테스트를 약화하지 않는다. 기대값을 바꿔야 하면 이유를 적는다.
