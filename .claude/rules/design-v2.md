# 버전 2·3 디자인 하네스 (2026-10-11)

**적용 시점**: `src/web/src/v2/`, `src/web/src/v3/` 를 고칠 때. 버전 1(`App.tsx`)은 `ui-design.md`(One UI)를 따른다.
멘토 제공 '프론트엔드 하네스 레퍼런스'를 이 제품에 맞게 추린 것. 원칙: "더 예쁘게"를 반복하지 말고 정본 하나에 맞춘다.

## 고정 맥락
- 실시간 제품 화면이다(랜딩 페이지 아님). 사용자는 횟집 사장님(50~60대, 새벽, 갤럭시 크롬, 한 손)이 주, 관광객이 부.
- 3초 안에 "다음 배가 몇 시에 무엇을 싣고 오나"가 보여야 한다.
- 범위는 `v2/`·`v3/` 뿐. 공용 `components/` 와 버전 1은 고치지 않고, 공용 부품 모양은 `.v2` 범위 CSS로만 덮는다.

## 스타일 정본
- 토큰은 `v2/v2.css`(`.v2` 안에서만 기존 토큰을 덮음). 이 밖의 색·글꼴·간격을 새로 만들지 않는다.
- 글꼴 Pretendard 고정. 강조색은 네이비(`primary-dark`) 하나. 오렌지는 **입항 시각·입항 알림**에만.
- 아이콘은 `v2/Icon.tsx` 한 벌(선 2px, 둥근 끝). 이모지를 아이콘으로 쓰지 않는다.
- 접근성은 `ui-design.md` 그대로: 터치 44px, 대비 4.5:1(큰 글자 3:1), 글자 200%, 색 + 글자로 상태 전달, 움직임 줄이기 존중.

## 순서 (스킬 역할)
1. 덜기 — ponytail + Impeccable `distill`: 같은 정보가 두 번 나오면 하나를 뺀다. 빼는 목록을 먼저 보여 주고 승인받는다.
2. 진단 — `redesign-existing-projects` 점검표, `ui-ux-pro-max --domain ux` 개별 검색. 제품 종류에 안 맞는 추천(랜딩용 글꼴·히어로 등)은 버린다.
3. 고치기 — 아이콘은 Runeicons outline(Apache-2.0, 출처 주석 유지), 모션은 Kinetics·transitions.dev 의 CSS만 참고.
4. 마무리 — Impeccable `polish` (수정 전 `craft-floor.md`).
5. 감사 — `web-design-guidelines`(file:line), Impeccable `detect`, 브라우저 스크린샷.

## 금지
- npm 의존성 추가(스택 변경 → CLAUDE.md 절차).
- 숫자를 화면에서 지어내기(숫자는 서버 값 그대로). sim/live 표시 숨기기.
- 카드 안 카드, 굵은 색 왼쪽 테두리, 그라데이션 글자, 제목 위 작은 머리말(eyebrow).
