# 에러 처리 규칙

**적용 시점**: 항상. 예외를 잡거나 사용자에게 오류 문구를 보여주는 모든 코드.

## 금지 / 허용
- 에러를 조용히 삼키지 않는다. 잡았으면 로그를 남기거나 다시 던진다.
- 사용자에게 보여주는 문구에는 스택 트레이스·내부 경로·비밀 값을 넣지 않는다.
- 사용자 문구는 한국어로, 무엇이 잘못됐고 무엇을 하면 되는지를 한 문장으로 쓴다.
- 예상 가능한 실패(입력 오류, 권한 없음, 외부 서비스 지연)는 각각 구분된 상태로 처리한다.

## 이유
- 삼켜진 에러는 재현이 불가능한 버그가 된다.
