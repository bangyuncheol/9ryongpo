`.claude/skills/deploy/` 스킬을 로드하고 배포 절차에 따라 배포 전 점검을 수행한다. 대상: $ARGUMENTS (비어 있으면 현재 브랜치)

## 출력 형식
1. 테스트 결과
2. 미적용 마이그레이션 — `migrations.md` 대기 목록 기준
3. 환경 변수 누락 여부 — 이름만, 값은 적지 않는다
4. 회귀 QA 핵심 항목 결과
5. 배포 가능 여부 판단과 근거

작성 시 준수사항:
- 실제 배포는 오너가 명시적으로 요청할 때만 실행한다.
- 점검 중 발견한 문제는 고치지 말고 보고한다.
