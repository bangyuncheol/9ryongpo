---

다음 데이터베이스 변경에 대한 계획을 작성하고, 마이그레이션 파일은 아직 만들지 말고 승인을 기다린다. 요청: $ARGUMENTS

## 출력 형식
1. 변경 내용 — 테이블·컬럼·인덱스·정책 단위로
2. 이유 — 어떤 기능 때문인지
3. 데이터 영향 — 기존 데이터 손실·변환 여부, 백업 필요 여부
4. 마이그레이션 — 파일 이름, 순서, 되돌리기 방법
5. 코드 영향 — 타입·쿼리·API 중 바뀌는 곳
6. 문서 갱신 — `db-schema` 스킬, `deploy/migrations.md` 갱신 항목

작성 시 준수사항:
- `.claude/rules/database.md` 와 `db-schema` 스킬을 먼저 읽는다.
- 승인 전에는 마이그레이션 파일을 만들지 않는다.
