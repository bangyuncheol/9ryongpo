# 배포

## 0. 문서 목적
현행 배포 절차의 정본. 배포 환경이 정해지면 채운다.

## 참고 파일 안내
- **`migrations.md`** — 프로덕션 적용 대기 중인 마이그레이션 목록

## 배포 절차
1. 테스트 통과 확인
2. `.claude/skills/qa-regression/checklist.md` 관련 항목 확인
3. `migrations.md` 대기 목록에 미적용 항목이 있으면 먼저 적용 계획 확인
4. 배포 (플랫폼 미정)
5. 배포 후 핵심 흐름 1회 수동 확인
