결과 표기: ✅ 통과 / ❌ 실패 / ⏭ 해당 없음. 실패는 `.claude/skills/project-history/bug-fix.md`에 기록.

## 공통
- [ ] `cd src/server && uv run pytest` 전부 통과
- [ ] 서버 시작 로그에 `어선 명부 202척 갱신`, `auction_stats … 적재`, `서버 준비 완료`
- [ ] `/api/health` → `fleet` 202, `sensors` 11, `auction_rows` > 0
- [ ] 서버 로그에 `serviceKey` 문자열이 없다(키 유출 점검)
- [ ] 브라우저 콘솔에 오류가 없다

## 화면
- [ ] 지도에 위판장★, 배● 50척(교통 센서는 표시하지 않음). 항상 떠 있는 라벨은 다음에 들어올 1척
- [ ] 배지: sim 은 주황, live 는 미갱신(마지막 2025-04-27)
- [ ] 폰 폭(360px)에서 가로 스크롤 없음
- [ ] 05:30까지 재생해도 화면이 길어지지 않는다: 보낸 알림 2건(최대 5건 보관)·입항 예보 5척·최근 질문 1개(최대 3개 보관)만 펼침, 나머지는 '더보기'
- [ ] 지도 왼쪽 아래 범례(위판장·입항 중·입항·조업·대기)
- [ ] (갤럭시) 지도에서 배 점을 탭하면 이름·업종·상태가 뜬다
- [ ] "43톤 자망선 언제 와?" 다음 "그 배는 뭐 싣고 와?" → 제33안성호로 이어서 답한다

## 데모 장면 (설계 §9, `/?admin=1`)
- [ ] 03:00 → 입항 중 0척(연안자망 3척은 조업·대기)
- [ ] 03:10 → 연안자망 3척 ETA 04:25·04:30·04:35, 어종 붉은대게 약 79%·골뱅이 약 10%
- [ ] 03:10 알림 카드의 '보낸 알림'에 "04:25~04:35 자망선 3척 입항 예정 · 붉은대게·골뱅이 가능성. 경매 09:00(기본값)"(LLM이 다듬었으면 숫자만 같으면 통과)
- [ ] 03:30 이후 제33안성호(자망 43t) ETA 04:45 전후
- [ ] 04:30 이후 "오늘 오징어 있어?" → 제33성한호(채낚기 29t, 05:27 전후)
- [ ] "43톤 자망선 언제 와?" → 도구 호출 기록이 흐르고 제33안성호 ETA
- [ ] "작년 10월 붉은대게 얼마였어?" → 2022~2025 kg당 실적, "예측하지 않습니다"
- [ ] "대게 들어오면 알려줘" → 알림 카드가 붉은대게로 준비되고 화면이 그쪽으로 이동
- [ ] 03:00으로 되감고 다시 재생하면 03:10 알림이 다시 나간다(보낸 알림에는 한 번만)
- [ ] "실데이터로 전환" → 배 50척이 멈춘 위치, 배지 미갱신. 다시 시뮬레이션으로 복귀
- [ ] 토큰 없이 진행 막대 조작 → "관리자만 시계를 조작할 수 있습니다…"
