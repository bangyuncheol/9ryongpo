# 회귀 QA

## 0. 문서 목적
자동 테스트로 잡기 어려운 사용자 흐름을 손으로 확인하는 체크리스트. 기능이 늘 때마다 항목을 추가한다.

## 참고 파일 안내
- **`checklist.md`** — 영역별 체크리스트 본문

## 사용 방법
- `/qa <영역>` 으로 호출하면 해당 영역 항목만 골라 수행하고 결과를 표로 보고한다.
- 실패 항목은 `.claude/skills/project-history/bug-fix.md` 에 기록한다.
