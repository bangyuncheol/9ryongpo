# 요구사항

## 0. 문서 목적
이 스킬은 **현행 스펙**이다. 이 기능은 이렇게 동작한다는 내용을 적는다. 하지 마라·해야 한다는 규칙은 `.claude/rules/` 로.

## 참고 파일 안내
- **`features.md`** — 기능 목록과 각 기능의 동작 기준
- **`flows-and-pages.md`** — 사용자 흐름, 페이지·라우트·API 엔드포인트 목록

## 요약
- 서비스 정체성: 미정. 오너 확정 후 채운다.
- MVP 범위: 미정. 오너 확정 후 `features.md` 에 채운다.
