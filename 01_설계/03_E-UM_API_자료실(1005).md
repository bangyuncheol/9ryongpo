| 항목 | 내용 |
|---|---|
| 호출 형식 | `GET https://genix.pohang-eum.kr/dpg/<경로>` |
| 인증 | 모든 API에 쿼리 파라미터 `serviceKey` 필수. 사이트 로그인 후 발급, **API별 활용신청** 필요(미신청 시 401) |
| 응답 구조 | `id`, `status`, `data`로 감싸짐. 아래 응답 표는 `data` 안의 항목 |
