# 배마중 데모 영상 — 촬영 가이드와 조립 절차

가로 1920×1080, 약 84초. 촬영분 7개(A~G)를 정해진 파일 이름으로 넣고 두 줄 명령을 돌리면 완성된 mp4가 나온다.
촬영 전에도 자리표시 영상으로 전체를 미리 볼 수 있다(`demo.mp4`).

## 1. 장면표 (길이는 `scenes.json`에서 바꿀 수 있음)

| 순서 | 파일 | 길이 | 화면 구성 | 내용 |
|---|---|---|---|---|
| A | `A.mp4` | 14초 | 촬영분 전체 화면 | 새벽. 할아버지 하소연 → 청년 등장 "우리에겐 배마중이 있잖아요!" → "어디서 나온 거야 이놈 새끼!!" |
| B | `B.mp4` | 24초 | **왼쪽 45% 촬영분 · 오른쪽 앱 화면** | 청년이 오른쪽(앱)을 가리키며 설명. 앱 화면은 자동으로 홈 → 입항 예보 → 알림 신청 → 출발 시각 순으로 움직임 |
| C | `C.mp4` | 4초 | 전체 화면 | "이제 허탕치실 일 없겠죠?" |
| D | `D.mp4` | 5초 | 전체 화면 | "호호 좋네… 그런데 눈도 침침하고 안 보여~" |
| E | `E.mp4` | 5초 | 전체 화면 | "그래서 전화로도 가능합니다!" + 전화 거는 모션, 할아버지에게 건넴 |
| F | `F.mp4` | 24초 | **왼쪽 45% 촬영분 · 오른쪽 통화 처리 화면** | 할아버지 통화. 오른쪽에 AI 인사 → 받아쓰기 → 도구 호출 5단계 → 답변 → 끝인사가 자동으로 뜸 |
| G | `G.mp4` | 8초 | 전체 화면 → 4.5초부터 밝아지며 로고 | 하이파이브. 뒤쪽 3.5초는 로고가 덮으니 정지해도 됨 |

자막은 `scenes.json`의 `lines`대로 자동으로 들어간다(화자 태그 + 대사). 촬영 후 실제 말한 타이밍에 맞춰 `t`(장면 시작 기준 초)와 `dur`만 고치면 된다.

## 2. 촬영할 때 지킬 것

**공통**
- 가로(16:9)로 찍는다. 세로로 찍으면 양옆이 잘린다.
- 각 장면은 표의 길이보다 **2~3초 길게** 찍는다. 긴 건 자동으로 잘리고, 짧으면 뒤가 검게 남는다.
- 카메라 고정(삼각대). 대사는 자막이 따로 들어가므로 녹음이 좀 흐려도 된다. 다만 촬영 소리는 그대로 쓰이니 배경 소음은 줄인다.
- 세로 1080p 이상, 30fps 권장. 파일은 mp4(H.264)면 바로 되고, 다른 형식이면 아래 변환 명령으로 바꾼다.

**분할 장면 B·F (가장 중요)**
- 사람은 **프레임 왼쪽 45% 안에** 있어야 한다. 오른쪽 55%는 앱/통화 화면이 덮는다.
- 카메라 뷰파인더에서 왼쪽 절반보다 조금 좁은 영역을 상상하고 그 안에서만 움직인다. 손짓으로 오른쪽을 가리키는 건 좋다(손은 선을 넘어도 됨).
- F에서 청년은 전화를 건네준 뒤 왼쪽 바깥으로 빠진다.
- F의 할아버지 대사 타이밍은 오른쪽 화면과 맞춰야 자연스럽다:
  - 0~5초: 전화 받고 듣기 (AI 인사가 1초부터 나옴)
  - **5초: "오늘 대게 들어오나? 몇 시에 가면 돼?"**
  - 8~19초: 듣기 (쿠션 "네, 확인해 볼게요." → 처리 → 답변)
  - **19초: "고마워요."**
  - 20.6초~: 끝인사 듣고 전화 내림
  - 촬영 때 누가 옆에서 초를 세어 주거나, 미리 만든 `demo.mp4`의 F 구간(52초~76초)을 폰으로 틀어 놓고 그 소리에 맞춰 연기하면 가장 쉽다.

**장면 G**
- 하이파이브 뒤 4.5초 지점부터 화면이 아이보리로 밝아지며 로고가 뜬다. 하이파이브는 앞 4초 안에.

## 3. 촬영분 넣고 조립하기 (윈도우·맥 공통)

```
cd brag-output/demo

# 1) 촬영분을 같은 이름으로 복사 (자리표시 영상을 덮어쓴다)
#    composition/assets/live/A.mp4 ... G.mp4

# 2) (선택) 길이·자막 타이밍 수정: scenes.json

# 3) index.html 다시 생성 → 점검 → 렌더
python build.py
cd composition
npx hyperframes check
npx hyperframes render --quality looks --output ../demo.mp4
```

- `check`에서 오류가 0이어야 렌더한다. 경고(sub-composition 권고 등)는 무시해도 된다.
- 렌더는 이 PC에서 84초 기준 약 4~5분. 미리보기만 보려면 `--quality draft`.
- 다른 형식(mov, 세로 촬영 등)을 mp4로 바꾸기:
  `ffmpeg -i 원본.mov -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" -r 30 -c:v libx264 -crf 20 -c:a aac composition/assets/live/A.mp4`
- 자리표시 영상을 다시 만들려면 `python make_placeholders.py` (이미 촬영분이 들어간 파일은 건드리지 않는다).

## 4. 바꿔도 되는 것

- `scenes.json` `phone_number_text`: 통화 화면에 표시할 번호. 지금은 `070-0000-0000`(가짜). 실제 070 번호를 넣으려면 여기만 바꾼다.
- `scenes.json` `music.level`·`level_app`: 배경음악 크기(0~1). 촬영 대사가 묻히면 `level`을 0.1로.
- 통화 대사(`call`): 실제 통화 녹취로 바꿔도 된다. `ai` 문장은 마침표마다 한 문장씩 차례로 뜬다.
- 장면을 빼거나 순서를 바꾸려면 `scenes` 배열에서 항목을 지우거나 옮긴다. 단 B·F·G는 각각 앱 패널·통화 패널·아웃트로가 붙어 있어 id를 유지해야 한다.

## 5. 파일 구성

```
demo/
  scenes.json           장면표(길이·자막·통화 대사·번호·음악 크기)
  build.py              scenes.json → composition/index.html 생성 + 폰트 서브셋
  make_placeholders.py  촬영 전 자리표시 영상 생성
  촬영가이드.md         이 문서
  demo.mp4              렌더 결과
  composition/
    index.html          생성된 영상 구성(직접 고치지 말 것 — build.py가 덮어씀)
    assets/live/        촬영분 A~G.mp4 (여기만 바꾸면 됨)
    assets/music, sfx   배경음악·효과음 (brag 번들, CC0)
    assets/fonts        Noto Sans KR 서브셋
```
